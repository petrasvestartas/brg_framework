# Installation

```bash
pip install brg_framework
```

## What is installed

| Package | What it is |
| --- | --- |
| `compas_framework` | The COMPAS framework. It installs `compas`, `compas_cgal`, `compas_gmsh`, `compas_libigl`, `compas_model`, `compas_session`, `compas_shapeop` and `compas_viewer` |
| `compas` | The COMPAS core |
| `compas_fd` | Force density |
| `compas_dr` | Dynamic relaxation |
| `compas_tna` | Thrust network analysis |
| `compas_tno` | Thrust network optimisation |
| `compas_dem` | Discrete element models |
| `compas_ags` | Algebraic graph statics |
| `compas_viewer` | The viewer |
| `brg` | The command, with the skill for coding agents |

Run `brg --help` to see the command.
