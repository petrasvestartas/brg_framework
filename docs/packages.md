# Packages

`pip install brg_framework` installs all of these.

## Block Research Group

| Package | Method | Docs |
| --- | --- | --- |
| `compas_fd` | Force density | [compas_fd](https://blockresearchgroup.github.io/compas_fd) |
| `compas_dr` | Dynamic relaxation | [compas_dr](https://blockresearchgroup.github.io/compas_dr) |
| `compas_tna` | Thrust network analysis | [compas_tna](https://blockresearchgroup.github.io/compas_tna) |
| `compas_tno` | Thrust network optimisation | [compas_tno](https://blockresearchgroup.github.io/compas_tno) |
| `compas_dem` | Discrete element models | [compas_dem](https://blockresearchgroup.github.io/compas_dem) |
| `compas_ags` | Algebraic graph statics | [compas_ags](https://blockresearchgroup.github.io/compas_ags/latest) |

## COMPAS

| Package | What it is |
| --- | --- |
| `compas_framework` | The [COMPAS framework](https://github.com/compas-dev/compas_framework). It installs `compas`, `compas_cgal`, `compas_gmsh`, `compas_libigl`, `compas_model`, `compas_session`, `compas_shapeop` and `compas_viewer` |
| `compas` | The COMPAS core |
| `compas_viewer` | The viewer |

## Tools

| Package | What it is |
| --- | --- |
| `brg_framework` | The `brg` command, with the skill for coding agents |
