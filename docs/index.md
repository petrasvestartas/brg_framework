# BRG framework

BRG framework installs the Block Research Group packages in one step.
It builds on the [COMPAS framework](https://github.com/compas-dev/compas_framework), which is installed with it. Code written with BRG framework follows the [COMPAS agent guides](https://github.com/compas-dev/compas_framework/blob/c3-upgrade/AGENTS.md).

See [Installation](installation.md) and the list of [Packages](packages.md).
