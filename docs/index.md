# BRG framework

BRG framework installs the Block Research Group packages in one step.

- [compas_fd](https://blockresearchgroup.github.io/compas_fd)
- [compas_dr](https://blockresearchgroup.github.io/compas_dr)
- [compas_tna](https://blockresearchgroup.github.io/compas_tna)
- [compas_tno](https://blockresearchgroup.github.io/compas_tno)
- [compas_dem](https://blockresearchgroup.github.io/compas_dem)
- [compas_ags](https://blockresearchgroup.github.io/compas_ags/latest)
