# Documentation of BRG framework

BRG framework installs the Block Research Group packages in one step.
It also ships the `brg` command, a skill for coding agents and the method theory.

| Method | Package | Docs |
| --- | --- | --- |
| Force density | `compas_fd` | [compas_fd](https://blockresearchgroup.github.io/compas_fd) |
| Dynamic relaxation | `compas_dr` | [compas_dr](https://blockresearchgroup.github.io/compas_dr) |
| Thrust network analysis | `compas_tna` | [compas_tna](https://blockresearchgroup.github.io/compas_tna) |
| Thrust network optimisation | `compas_tno` | [compas_tno](https://blockresearchgroup.github.io/compas_tno) |
| Discrete element model | `compas_dem` | [compas_dem](https://blockresearchgroup.github.io/compas_dem) |
| Algebraic graph statics | `compas_ags` | [compas_ags](https://blockresearchgroup.github.io/compas_ags/latest) |
