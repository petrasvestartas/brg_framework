# COMPAS Python Examples

`compas_fd` is the force density package of COMPAS, and `compas_viewer` displays the 3D equilibrium geometry. Install them with `pip install compas_fd compas_viewer`, or `uv add compas_fd compas_viewer`.

The original `compas_fd` examples and standalone Python versions of every topology in the COMPAS FormFinder PDF are collected here. Type any command below to view its Python script (with `compas_viewer`) and run it locally.

## Original `compas_fd` examples

- `mcp_brg_fd_compas_hypar`: [Hypar: one free node and four supports](10_compas/01_hypar.md) (`fd_hypar.py`)
- `mcp_brg_fd_compas_selfweight`: [Selfweight: nodal loads from tributary areas](10_compas/02_selfweight.md) (`fd_selfweight.py`)
