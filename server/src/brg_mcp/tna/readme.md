# Thrust network analysis

Thrust network analysis finds compression only vaults and shells for vertical loads. It splits the three dimensional equilibrium of a network of forces in two parts. The horizontal part is solved in plan with two diagrams: the form diagram, which is the plan of the network, and the force diagram, whose edge lengths are the horizontal forces. When every pair of corresponding edges is perpendicular, the plan is in equilibrium. The vertical part is then a linear system of equations, the same as in the force density method, that gives the heights of the nodes for a chosen scale of the force diagram: a larger scale gives a shallower vault. Changing the force diagram redistributes the forces, and this is how creases, lips, openings and ribs are designed. The method was developed for the analysis of historic masonry and is the basis of RhinoVAULT. It is independent from material properties; the thrust network only has to fit inside the thickness of the structure.
