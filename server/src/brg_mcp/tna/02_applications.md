Applications

# Geometry

- compression only vaults and shells in unreinforced masonry, cut stone or concrete
- shells with open, curved edges between point supports
- vaults with openings, creases, lips and ribs, shaped by the force diagram
- funicular floors and bridges
- safety assessment of historic masonry vaults: a thrust network that fits inside the masonry
