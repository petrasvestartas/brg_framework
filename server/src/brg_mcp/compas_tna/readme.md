# COMPAS TNA

`compas_tna` is the thrust network analysis package of COMPAS, paired with `compas_viewer` for 3D visualization. Install them with `pip install compas_tna compas_viewer`, or `uv add compas_tna compas_viewer`.

- Code: https://github.com/BlockResearchGroup/compas_tna
- Documentation: https://blockresearchgroup.github.io/compas_tna
- RhinoVAULT, the Rhino plugin built on it: https://blockresearchgroup.gitbook.io/rhinovault
- All ten COMPAS Python examples: `mcp_brg_tna_compas`
- Thrust network analysis: `mcp_brg_tna`
